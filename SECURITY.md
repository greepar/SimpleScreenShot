# Security Policy

## Supported versions

The latest published release is supported. GNOME Shell 46 on Ubuntu 24.04 is the current tested platform.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose screenshot contents, clipboard data, local files, or user input.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, GNOME Shell version, reproduction steps, impact, and any suggested mitigation. Reports will be acknowledged as soon as practical and coordinated disclosure is preferred.
